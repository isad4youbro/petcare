# Backend

Python 3.11+ обслуживает API и собранный frontend. Данные хранятся в SQLite. Для основного дневника дополнительных Python-пакетов не требуется; опциональные зависимости перечислены в requirements.txt.

Запуск из корня: `npm --prefix frontend ci`, `npm --prefix frontend run build`, `python backend/server.py`. Адрес: http://127.0.0.1:8000. Копируйте `.env.example` в приватный `.env` только если нужны внешние сервисы.

| Файл | Ответственность |
|---|---|
| server.py | HTTP-маршруты, валидация, транзакции, сборка состояния, сохранение питомцев и записей |
| username_auth.py | Уникальные логины, хеши паролей, создание аккаунтов и вход |
| care_schedule.py | Даты повторных процедур и курсов |
| demo_data.py | Вымышленные истории шести питомцев |
| public_tags.py | Публичные QR-карточки, отчёты, согласия и очередь уведомлений |
| telegram_runtime.py | Команды бота, polling и напоминания |
| avatar_config.py, avatar_catalog.json | Проверка конфигурации пиксельного питомца |
| email_auth.py | Сохранённый совместимый API входа по почтовому коду |
| push_service.py | Опциональный Web Push, по умолчанию выключен |
| setup_bot.py | Настройка команд собственного Telegram-бота |
| test_*.py | Проверки API, изоляции данных, расписаний и меток |

Описания запросов: [API](../docs/API.md), [OpenAPI](../docs/openapi.json). Схема взаимодействия: [архитектура](../docs/architecture.md). Этот backend не работает на GitHub Pages: там используется отдельное локальное демо.
