# RFC: два режима PetCare

Решение: сохранить серверное приложение и добавить самостоятельный локальный адаптер для статического портфолио. Причина: GitHub Pages не запускает Python и SQLite. Общие React-компоненты остаются одними; данные выбираются в data.js по флагу сборки. Публичные ссылки в Pages используют query-параметр.
