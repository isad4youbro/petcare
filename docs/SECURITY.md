# Данные и безопасность

## Портфолио

Публичный снимок не включает историю командного Git, `.env`, рабочие SQLite-базы, chat_id, токены и личный номер владельца Торпедки. В демо используются вымышленные истории. Данные посетителя не отправляются на API приложения; локальные записи и фото остаются в браузере. GitHub как хостинг может обрабатывать обычные HTTP-запросы к статическим файлам.

localStorage не является защищённым медицинским хранилищем. Не вводите чувствительные данные; используйте сброс демо или очистку данных сайта для удаления. Локальные изменения QR-карточки не публикуются для других пользователей.

## Серверный режим

Имена пользователей уникальны в SQLite; пароли хешируются PBKDF2-SHA256 с индивидуальной солью. Сессии используют HttpOnly cookies. Проверки владельца выполняются на сервере, а не только скрытием кнопок. Реальные секреты задаются через env, не через VITE-переменные.

Перед production-развёртыванием настройте HTTPS и secure cookies, резервные копии, ограничения reverse proxy, обновление зависимостей и мониторинг. QR-карточка по определению публична: публикуйте только согласованные контакты. Полный адрес доступен лишь при явном согласии; геолокация нашедшего запрашивается отдельно. Это описание механизмов, а не гарантия отсутствия уязвимостей или результат независимого аудита.
