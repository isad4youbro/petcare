# PetCare

Дневник помогает собрать наблюдения о здоровье, питании и важных датах питомца. Пиксельный редактор делает профиль узнаваемым; QR-карточка демонстрирует сценарий возвращения потерявшегося животного.

Публичная версия предназначена для знакомства с интерфейсом. Вымышленные истории не являются медицинскими рекомендациями. Ограничения локального демо описаны в основном README. Для настоящих владельцев и общей базы требуется собственный backend.
